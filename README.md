# LINEスタンプ生成アプリ（手順書）

ブラウザだけで、アバターを作り40枚のLINEスタンプ画像を生成・編集し、ZIPで保存する。インストール・サーバー不要。

## 起動

**スマホ（ホーム画面に置く）**: 公開版 https://claude.ai/artifact/PTin512TRL3qzPrtzgts89 を、claude.aiにログインした Safari / Chrome で開く。
- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: 右上の︙ →「ホーム画面に追加」
- 公開版ではAI生成は使えない（外部APIへの通信が許可されないため）。ZIP保存は確認ダイアログを経て保存される。

**PC**: `line-stamp-app` フォルダをPCに置き、`index.html` を Chrome / Edge / Safari で開く。

## 使い方（7ステップ）

| 画面 | 手順 | 操作 |
|---|---|---|
| 1 アバター | ① パーツ選択 | 性別・髪型・髪色・目の形・瞳の色・肌の色・服装・服の色・身長・体型を選ぶ。右のプレビューでイメージを確認。「おまかせ」でランダム生成 |
| 2 シチュエーション | ② 文言入力 | 1行＝1枚で40行入力。「/」で改行。文言から表情・ポーズ・装飾を自動割当 |
| 3 タッチ | ③ イラスト化 | かわいい／リアル／ゆるふわ／シリアスから選ぶ。文字のフォント・色・位置もここで設定 |
| 4-6 一覧・チェック・編集 | ④ 一覧生成 ⑤ チェック ⑥ 編集 | 40枚を8列×5行の一覧画像で表示。気になる1枚をクリック→文言・表情・ポーズ・装飾を変更、または手持ち画像で差し替え。「一覧画像をPNG保存」も可 |
| 7 保存 | ⑦ 切り分けて保存 | main/tab に使う絵を選び「ZIPをダウンロード」。一覧画像を40枚に切り分けて保存 |

入力内容はブラウザに自動保存される（差し替え画像は除く）。「すべて初期状態に戻す」でリセット。

## AI生成を使う場合（任意・有料）

イラストを画像生成AI（OpenAI `gpt-image-1.5` 既定）で描かせることもできる。

1. https://platform.openai.com/api-keys でAPIキーを作成し、支払い設定をしておく。
2. 「3 タッチ」で描画方法を **AI生成** にし、APIキーを入力。モデル・品質を選ぶ。
3. 「AIでキャラクター化」→ ①のパーツと③のタッチから基準キャラを生成（気に入るまで押し直し可）。
4. 「4-6」で「AIで未生成分を作成」→ 基準キャラを参照して40枚を生成（同時3枚、途中中止可）。
5. 気になる1枚はクリック →「AIへの追加指示」を入れて「この1枚をAIで再生成」。
6. 文言・装飾はアプリが重ねる（AIには文字を書かせない）。
7. 仕上がりを上げたいときは「参考画像」に目指す絵柄のイラストを入れる。
   - 「絵柄・クオリティだけ参考にする」: ①のアバターを、その絵柄で描く。
   - 「このキャラクターでスタンプを作る」: 参考画像のキャラクターそのものでスタンプを作る（自分で権利を持つ画像に限る）。
   - タッチは「アニメ（高品質）」、品質は「高」がおすすめ（費用は上がる）。

- 費用: キャラクター化1回＋40回の生成ぶんがOpenAIから請求される。品質「低」が最安。最新単価はOpenAIの料金ページで確認。
- APIキーは api.openai.com への送信にのみ使う。「この端末にキーを保存」をオンにしない限り保存しない。共用PCでは保存しないこと。
- 生成画像はブラウザ内（IndexedDB）に保存され、再読み込みしても残る。文言を②で変えた枠は未生成に戻る。
- 「403」が出る場合は、OpenAI側で組織の本人確認（Verify Organization）が必要なことがある。

## LINEスタンプメーカーへの取り込み

1. `line_stamps.zip` をスマホに送り、展開して画像を写真（カメラロール）に保存する。
2. LINEスタンプメーカーで「スタンプを作成」→ 写真から画像を選ぶ → 余白などを確認して保存。
3. 40枚そろえて申請する。

PCの LINE Creators Market から申請する場合は ZIP をそのまま一括アップロードできる。

## 出力仕様

| ファイル | サイズ | 備考 |
|---|---|---|
| `01.png`〜`40.png` | 370×320 | 透過PNG、余白10px（一覧画像から切り出し） |
| `main.png` | 240×240 | 文言なし |
| `tab.png` | 96×74 | 文言なし |

出力時に偶数px・1MB以下を自動チェックする。

## 注意

- 既定はプログラム描画（無料）。「リアル」は頭身・線・影を変えたタッチで、写真のような絵にしたい場合はAI生成を使う。
- フォントは Google Fonts を使用。オフライン時は端末のフォントで代替される。
- 審査ではオリジナル性が問われる。他者の画像やキャラクターで差し替えないこと。
