# 設計書（要件・アーキテクチャ・計画・開発標準）

## 1. 要件（Persona A）

**目的**: LINEスタンプメーカーに取り込める40枚のスタンプ画像を、アバター作成感覚で作る。

**業務フロー（ユーザー指定）**
1. パーツ選択でアバターを作り、プレビューでイメージを掴む
2. スタンプを使うシチュエーションの文言を入力
3. イラストのタッチ（かわいい／リアル／ゆるふわ／シリアス）を選んでイラスト化
4. 40枚を1枚の一覧画像（8列×5行）で生成
5. ユーザーがチェック
6. 一覧から指定した1枚を編集・修正
7. 一覧画像を40枚に切り分けてZIP保存

| 区分 | 内容 |
|---|---|
| パーツ | 性別3・髪型6・髪色・目の形4・瞳の色・肌の色・服装5・服の色・身長3・体型3 |
| 自動割当 | 文言のキーワード → 表情12・ポーズ8・装飾12（`LS.RULES`） |
| 編集 | 文言／表情／ポーズ／装飾の変更、画像差し替え、自動割当に戻す |
| 出力仕様 | 370×320・偶数px・透過PNG・1MB以下／main 240×240／tab 96×74／`01.png`〜`40.png` |
| 非機能 | ブラウザのみ（`file://`可）、外部JSなし、スマホ表示可、ダークモード対応、自動保存 |

**描画エンジン（③で切替）**
- プログラム描画（既定）: Canvasで描く。無料・オフライン。
- AI生成: OpenAI Images API `POST /v1/images/edits`（既定 `gpt-image-1.5`、`background=transparent`, `output_format=png`, `size=1024x1024`, `input_fidelity=high`）。
  - 選定理由: 透過PNGを直接出せる（LINE必須）、参照画像で同一キャラを維持できる、ブラウザから直接呼べる。
  - 流れ: プログラム描画のアバターを参照に「基準キャラ」を生成 → 基準キャラを参照に表情/ポーズ別に40枚生成 → 透明余白をトリミング → 文言・装飾はアプリが合成。
  - APIキー: 利用者が入力。送信先は api.openai.com のみ、保存は任意で localStorage のみ。生成画像は IndexedDB。
  - 429/5xx は指数バックオフで3回まで再試行、401/403 は一括生成を中止。

## 2. アーキテクチャ（Persona B）

```
line-stamp-app/
├─ index.html        5画面（①/②/③/④-⑥/⑦）
├─ css/style.css
├─ js/config.js      仕様・パーツ・タッチ・表情/ポーズ/装飾・自動割当ルール（データのみ）
├─ js/draw.js        描画共通（図形・手足・色計算）
├─ js/avatar.js      アバター描画（髪/顔/体/服/腕ポーズ × タッチ）
├─ js/decor.js       装飾描画
├─ js/renderer.js    1枚合成（アバター＋装飾＋文言の自動フィット）
├─ js/sheet.js       文言解析・自動割当、一覧画像生成、セル単位再描画、切り分け
├─ js/zip.js         無圧縮ZIP生成
├─ js/ai.js          OpenAI呼び出し・プロンプト組立・透過トリミング・並列制御
├─ js/store.js       AI画像の保存（IndexedDB）
└─ js/app.js         ウィザードUI・状態・保存
```

- 依存: `app → sheet → renderer → avatar / decor → draw`、`app → zip`。描画系はDOM非依存。
- 正本は一覧画像（2960×1600）。⑥の編集は該当セルのみ再描画し、⑦は一覧から切り出す。
- 拡張点: パーツ＝`AVATAR_FIELDS`＋`avatar.js` の分岐、タッチ＝`STYLES` に1行、ポーズ＝`POSE`、ルール＝`RULES`。

## 4. 開発標準（Persona D）

- 1ファイル1責務。描画関数は `(ctx, box/g, ...)` で座標を受け取り、DOMに触れない。
- 寸法は `LS.SPEC` を参照。アバター内部は頭の高さ `H`・顔半径 `rx/ry` 相対で記述。
- 選択肢・文言・ルールは `config.js` に集約。
- `localStorage` は利便機能のみ、読み書きは try/catch。
- Webフォントは遅延ロードのため `loadingdone` で再描画、出力前に `document.fonts.ready` を待つ。
- 検証: Playwright で各ステップを操作し、ZIP内の全PNGが偶数px・370×320以内・RGBA・1MB以下であることを確認。
